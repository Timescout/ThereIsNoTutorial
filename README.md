### About this project
A game about finding the soulution through puzzling out what moves you can make made using the Godot game engine.

This was a submission to the GameMaker's Toolkit 2026 Game Jam which had the theme of "Count Down". I created a mechanic that counted the number of errors the player made each round, and if the counter reaches 0 the player is sent back to the beginning of the game. 

You can download the release of the game here: [Itch.io](https://timescout.itch.io/there-is-no-tutorial) or download the Godot project in this repo.

I'm not super happy with this code because it is very tightly coupled, there are no tests, and it isn't very organized or expandible. Since it was made in 3 days for a game jam these problems are not enough for me to private the project or redo it, but this is not the standard I like to keep myself to.
